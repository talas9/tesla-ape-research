# Issue 271

**Activation flags do not install a new software image.**

A Model 3 HW4 reporter in China asked whether the project could move an officially installed FSD v13.2.9 on vehicle software 2025.8.3.6 to v14. The maintainer said software builds are delivered through Tesla OTA and that the project does not install or upgrade them. [Maintainer reply](https://github.com/hypery11/flipper-tesla-fsd/issues/271#issuecomment-6754836873).

Review covered the issue and 3 visible comments. [Upstream discussion](https://github.com/hypery11/flipper-tesla-fsd/issues/271).
