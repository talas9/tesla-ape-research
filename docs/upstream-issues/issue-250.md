# Issue 250

**A board-port request is not delivered support.**

The contributor proposes a three-channel board port based on a third-party closed build. The [maintainer](https://github.com/hypery11/flipper-tesla-fsd/issues/250#issuecomment-6291863857) explains the existing framework does not support that processor, notes a different Wi-Fi path, and explicitly declines to ship an untested environment or receive the closed binary. It requests a minimal read-only bring-up and schematic-backed pins.

Review covered the issue and 1 visible comment. [Upstream discussion](https://github.com/hypery11/flipper-tesla-fsd/issues/250).
