# Issue 237

**A varied-pressure comparison resolves a source-specific wheel order.**

The [maintainer](https://github.com/hypery11/flipper-tesla-fsd/issues/237#issuecomment-6159747252) finds the reported `0x219` seven-byte form differs from a public decoder and initially leaves wheel order unknown. A [reporter tests changed pressures](https://github.com/hypery11/flipper-tesla-fsd/issues/237#issuecomment-6203020988). The [maintainer comparison](https://github.com/hypery11/flipper-tesla-fsd/issues/237#issuecomment-6292169961) resolves the four-column order for that vehicle, and a [later reporter confirms the update](https://github.com/hypery11/flipper-tesla-fsd/issues/237#issuecomment-6542496088).
